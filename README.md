## 📌 About The Project

Welcome to my Machine Learning Practice Repository!

In this project, I explored and implemented three
powerful regularization techniques used in Machine Learning:

- 🔵 Ridge Regression (L2 Regularization)
- 🟢 Lasso Regression (L1 Regularization)
- 🟣 Elastic Net Regression (L1 + L2 Regularization)

The main objective of this project is to understand how
regularization techniques work, train regression models,
compare their coefficients, and evaluate their predictive
performance using real-world datasets.

---

## 🎯 Project Objectives

- Understand Ridge, Lasso, and Elastic Net Regression.
- Implement regularization techniques using Python.
- Perform model training and prediction.
- Analyze and compare model coefficients.
- Evaluate model performance using regression metrics.
- Understand the practical application of regularization.

## 📈 Model Evaluation Metrics

I used the following regression evaluation metrics
to analyze model performance:

| Metric | Description |
|--------|-------------|
| MAE | Mean Absolute Error |
| RMSE | Root Mean Squared Error |
| R² Score | Coefficient of Determination |

These metrics help evaluate prediction errors
and understand how well the models perform.
